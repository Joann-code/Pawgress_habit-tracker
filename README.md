A minimalist, nurturing habit tracker web application designed to help users build positive routines without the anxiety of high-pressure streaks. 

## ✨ Features

* **Authentication:** Secure Sign Up and Log In via Firebase.
* **Virtual Companion:** Choose and name your pet to accompany your journey.
* **Habit Tracking:** Add daily habits and check them off to earn food points.
* **Dynamic Calendar:** Visual history of your progress with cute paw stamps.
* **Cloud Sync:** Real-time data saving using Firebase Firestore.

## 🛠️ Tech Stack

* HTML5 & Vanilla JavaScript
* Tailwind CSS
* Firebase (Auth & Firestore)
* Vercel (Hosting)
